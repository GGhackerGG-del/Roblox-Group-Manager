# Limited.Ink — Запуск на своём компьютере

## Что нужно

- **Docker Desktop** — скачать бесплатно: https://www.docker.com/products/docker-desktop/
- Токен Telegram бота (уже есть)

> Docker — это программа, которая запускает приложение в изолированном контейнере. Устанавливается один раз, больше ничего не нужно.

---

## Первый запуск (Windows)

1. Установите **Docker Desktop** и запустите его (должен появиться значок кита в трее)

2. Скачайте проект или скопируйте папку `deploy/` вместе с корнем проекта на компьютер

3. Откройте папку `deploy/` и дважды кликните на **`start.bat`**

4. Скрипт сам создаст настройки и спросит токен бота — вставьте его

5. Первый запуск займёт ~5 минут (скачивает зависимости, собирает проект)

6. Откройте браузер: **http://localhost:3000**

---

## Первый запуск (Mac / Linux)

```bash
cd deploy
chmod +x start.sh
./start.sh
```

## Ручная настройка (если скрипт не подошёл)

### 1. Настройте токен бота

Скопируйте шаблон и заполните:

```bash
cp deploy/.env.example deploy/.env
```

Откройте `deploy/.env` и укажите:

```
TELEGRAM_BOT_TOKEN=ваш_токен_бота
```

Остальные секреты (`JWT_SECRET`, `SESSION_SECRET`, `DB_PASSWORD`) можно оставить или заменить любыми случайными строками.

### 2. Запустите

```bash
cd deploy
docker compose --env-file .env up -d --build
```

### 3. Инициализируйте базу данных (только при первом запуске)

```bash
docker compose exec -T app sh -c "npx drizzle-kit push --config lib/db/drizzle.config.ts"
```

### 4. Откройте сайт

Перейдите на **http://localhost:3000**

## Управление

| Команда | Действие |
|---|---|
| `docker compose logs -f app` | Смотреть логи |
| `docker compose restart app` | Перезапустить приложение |
| `docker compose down` | Остановить всё |
| `docker compose up -d --build` | Пересобрать после обновления кода |
| `docker compose down -v` | Остановить и **удалить данные** ⚠️ |

> Все команды выполнять из папки `deploy/`

## Telegram бот

Бот запускается автоматически вместе с приложением если указан `TELEGRAM_BOT_TOKEN` в `.env`.

Команды бота:
- `/start` или `/admin` — открыть панель (только для вас, как администратора)
- **➕ Выдать подписку** — создать лицензионный код (week/month/lifetime)
- **📋 Список лицензий** — последние 20 кодов
- **🔍 Проверить код** — проверить статус лицензии

## Данные и бэкапы

База данных хранится в Docker volume `pgdata` — данные сохраняются между перезапусками.

Бэкап:
```bash
cd deploy
docker compose exec db pg_dump -U limitedink limitedink > backup_$(date +%Y%m%d).sql
```

Восстановление:
```bash
cat backup_YYYYMMDD.sql | docker compose exec -T db psql -U limitedink limitedink
```

```bash

cd deploy
docker compose logs app

# Посмотреть логи базы данных
docker compose logs db

# Перезапустить
docker compose restart app
```
